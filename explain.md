# ScamShield BD — Project Guide & Architecture

This document explains what each file in the project does and how the full pipeline works end-to-end.

---

## 1. End-to-End Flow

```text
1. Synthetic Data & Augmentation (Offline Training Data Creation)
   src/gen_templates.py ──▶ data/synthetic_train.csv (1,560 balanced rows)
   src/augment.py       ──▶ data/augmented_train.csv (2,010 rows: +25% corrupted + 60 noise-only)

2. Baseline Training & Inference (Current Pipeline)
   data/sample.csv (86 labeled rows)
      │
      ▼  normalize() in src/normalize.py
   Cleaned training text
      │
      ▼  train_models() in src/train_baseline.py (fit ONLY on training data)
   TfidfVectorizer (char_wb, 2–5) + 3 Linear Classifiers (label, action, techniques)
      │
      ▼  Chunked inference (50,000 rows/chunk) on data/test.csv (# TEST DATA: inference only)
   Raw probabilities (label, action, T1..T6)
      │
      ▼  postprocess_chunk() + is_noise_only()
   Enforced ScamShield rules + clipped confidence
      │
      ▼  validate_submission()
   submission.csv (500,000 rows: id,label,techniques,action,confidence)
```

## 2. File-by-File Breakdown

### `PLAN.md`
The single source of truth for the **ScamShield BD (NSUCEC NeuraHack 2026 Preliminary)** task. It defines:
- **4 Prediction Targets**:
  - `label` (0–5): `0` Legitimate, `1` MFS/OTP scam, `2` Prize/lottery scam, `3` Fake job/investment, `4` Delivery/parcel phishing, `5` Promotional spam.
  - `techniques` (multi-label `T1`–`T6` joined by `|`, or `NONE`).
  - `action` (0–5): intended victim action (`0` none, `1` share credentials, `2` pay/transfer, `3` click link, `4` install app/join/task, `5` contact/reply).
  - `confidence` (`0.0`–`1.0`): probability that `label` is correct.
- **Priority Order**: `1 → 2 → 4 → 3 → 5 → 0`.
- **Hard Rules**: Never use `data/test.csv` for training or fitting anything (including vectorizers, thresholds, or calibrators).

---

### `data/`
- **`data/sample.csv`**: 86 labeled examples (`id,text,label,techniques,action`) covering English, Bangla script, Banglish, mixed text, multi-turn conversations (`|||`), and adversarial noise.
- **`data/synthetic_train.csv`**: 1,560 deterministic synthetic training rows (`260` per class `0–5`) with `scenario_id,group,text,label,techniques,action`, generated by `src/gen_templates.py`.
- **`data/augmented_train.csv`**: 2,010 rows (`label 0`: 385, `labels 1–5`: 325 each) combining `synthetic_train.csv`, 25% adversarially corrupted copies (`390` rows), and `60` noise-only rows, generated by `src/augment.py`.
- **`data/test.csv`**: 500,000 unlabeled rows (`id,text`). Read **only** during inference.
- **`data/sample_submission.csv`**: Reference submission file showing the required output schema.

---

### `src/normalize.py`
Handles adversarial text cleaning and noise detection without external dependencies.

- **`normalize(text: str) -> str`**:
  1. **Zero-width removal**: Strips `\u200B`, `\u200C`, `\u200D`, and `\uFEFF` used to break sensitive words (e.g. `Gr\u200boup` → `group`).
  2. **Unicode NFKC**: Normalizes compatibility characters via `unicodedata.normalize("NFKC", text)`.
  3. **Homoglyph mapping**: Translates Cyrillic and Greek lookalike characters (e.g. `а`, `е`, `о`, `р`, `с`) to Latin equivalents via `str.maketrans`.
  4. **Emoji removal**: Strips emoji/symbol ranges while keeping ASCII, Bangla (`\u0980–\u09FF`), and `|`.
  5. **URL & phone masking**: Replaces defanged/standard URLs (`hxxps://...[.]...`) with `<URL>` and masked/BD phone numbers (`01XXXXXXXXX`) with `<PHONE>`.
  6. **Repetition collapse**: Reduces 3+ consecutive repeated characters to 2 (e.g. `Facccebook` → `faccebook`), while preserving digits (e.g. `5000`) and conversation delimiters (`|||`).
  7. **Lowercasing & gibberish stripping**: Lowercases English text (preserving `<URL>`, `<PHONE>`, and uncased Bangla script), collapses whitespace, and strips long vowel-less or consonant-heavy gibberish tokens (e.g. `wkrjfejejrn`, `xkcdpl`).
- **`is_noise_only(text: str) -> bool`**:
  - Returns `True` if, after normalization, the text contains no `<URL>`/`<PHONE>`, fewer than 2 Bangla letters, and no meaningful English/Banglish words or known short acronyms (`ok`, `otp`, `pin`, `tk`, etc.).
- **Self-test (`if __name__ == "__main__":`)**:
  - Runs assertions for lookalike replacement, defanged URL/phone replacement, Bangla preservation, repeated-character collapse, delimiter preservation, and noise-only detection.

---

### `src/gen_templates.py`
Deterministically (`SEED = 42`) generates a diverse synthetic training dataset (`data/synthetic_train.csv`).

- **Entity Slots**: `{brand}` (14 BD brands: bKash, Nagad, Rocket, Upay, GP, Robi, Banglalink, Daraz, Pathao, Steadfast, SA Paribahan, Bdjobs, DBBL, City Bank), `{amount}`, `{link}`, `{phone}`, `{time}`, `{name}`, `{otp}`, `{order_id}`.
- **Template Library (`_template_bank`)**: 10 distinct `scenario_id`s per class (`0–5`) across English, Bangla script, Banglish, and mixed text.
- **Hard Negatives (`generate_hard_negatives`)**: Friends warning about scams while quoting fraudulent messages, genuine OTP warnings, and dispute alerts (`label=0`, `techniques='NONE'`, `action=0`).
- **Multi-Turn Conversations (`generate_conversations`)**: 2–5 turn chats joined by ` ||| ` with varied speaker formats (`S:/R:`, `A:/B:`, `[Sender]/[You]`, `Caller:/You:`, or none), delayed scam hooks, and Priority Order labeling.
- **Domain Shifts (`generate_domain_shifts`)**: Formal emails, call transcripts, and group/broadcast notices across all 6 classes.

---

### `src/augment.py`
Injects adversarial corruptions and noise-only samples into the synthetic dataset (`data/augmented_train.csv`).

- **`corrupt(text: str, level: float = 0.3) -> str`**:
  - Preserves `|||` delimiters and speaker prefixes (`S:`, `R:`, `A:`, `B:`, `[Sender]`, `[You]`, `Caller:`, `You:`).
  - Applies sensitive-word misspellings (`bKash`, `Nagad`, `OTP`, `PIN`, `parcel`, `account`, `verify`, `link`, `taka`), Latin→Cyrillic lookalike swaps, zero-width insertions, character repetitions/deletions, random spacing/merging, random capitalization, scam emojis (`🔥`, `💰`, `🎁`, `⚠️`, `❗`, `👉`), and gibberish tokens.
- **`generate_noise_only(n_samples: int = 60)`**:
  - Generates consonant clusters, keyboard smashes, and zero-width/emoji noise strictly labeled `label=0`, `techniques='NONE'`, `action=0`, `scenario_id='noise_only'`, `group='noise'`.
- **`augment_dataset(...)`**:
  - Combines `data/synthetic_train.csv`, 25% stratified corrupted copies (`390` rows), and `60` noise-only rows, shuffles with `SEED = 42`, and saves `data/augmented_train.csv`.

---

### `src/train_baseline.py`
Trains the baseline TF-IDF + Logistic Regression pipeline and produces `submission.csv`.

- **Reproducibility**: Fixes `random` and `numpy` seeds with `SEED = 42`.
- **`encode_techniques(series)`**: Converts pipe-delimited `T1|T2...` labels into a `(N, 6)` binary matrix.
- **`train_models(train_df)`**:
  - Normalizes training text and fits `TfidfVectorizer(analyzer="char_wb", ngram_range=(2, 5), sublinear_tf=True, min_df=2)` **strictly on training data**.
  - Fits three `class_weight="balanced"` `LogisticRegression` models (`label_clf`, `action_clf`, `OneVsRestClassifier` `tech_clf`).
- **Chunked Inference (`main`)**:
  - Streams `data/test.csv` in chunks of `50,000` rows (`# TEST DATA: inference only`) to keep memory low across 500,000 rows, calling only `.transform()` and `.predict_proba()`.
- **`postprocess_chunk(...)`**:
  - Forces `is_noise_only` rows to `label=0`, `techniques="NONE"`, `action=0`.
  - Enforces class `0` and `5` → `techniques="NONE"` and `action=0`.
  - Enforces class `1–4` → non-empty `techniques` and non-zero `action`.
  - Sets `confidence` to the clipped max `label` probability.
- **`validate_submission(sub_path, expected_rows)`**:
  - Verifies `submission.csv` has 500,000 rows, exact columns `id,label,techniques,action,confidence`, unique IDs, no NaNs, valid ranges, and consistency rules.

---

### `submission.csv`
The generated 500,000-row prediction file ready for Kaggle submission, validated by `validate_submission()`.

---

## 3. How to Run

1. **Test text normalization**:
   ```bash
   python src/normalize.py
   ```
2. **Generate synthetic & augmented training data**:
   ```bash
   python src/gen_templates.py
   python src/augment.py
   ```
3. **Train baseline and generate `submission.csv`**:
   ```bash
   python src/train_baseline.py
   ```

## 4. Planned Next Steps (from `PLAN.md`)
1. `src/split.py`: Group-based validation split (by `scenario_id`/`group`) to measure generalization without leakage across clean, corrupted, long/formal, and novel-scenario subsets.
2. Train `src/train_baseline.py` on `data/augmented_train.csv` (using `sample.csv` as a held-out sanity check) and tune per-technique thresholds on validation.
3. `src/train_transformer.py`: Multi-task multilingual encoder (`xlm-roberta-base` / `mdeberta-v3-base`) ensembled with the TF-IDF baseline.
4. `src/calibrate.py`: Temperature scaling on validation logits to improve the `confidence` Brier score.
